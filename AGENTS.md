## Git Rules

### Local Working Tree Rules

The following rules apply when working in the same local working tree as me. They do not apply when working in a separate worktree or in a cloud environment.

- **Do not commit changes.** Do not commit changes. Only I can commit changes.
- **Do not use the Git branch.** Do not create, checkout, switch, or otherwise modify branches. The branch is reserved for my use.
- **Do not modify the Git index.** Do not stage or unstage changes. Only modify the working tree. I use the staging area to distinguish your changes from mine.
- **Do not use the Git stash.** Do not create, apply, pop, drop, or otherwise modify stashes. The stash is reserved for my use.
